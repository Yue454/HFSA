# HFSA
This repository contains the official PyTorch implementation of our paper: "HFSA: Heterogeneous Teacher-Student Networks with Frequency-Spatial Fusion and Axial Feature Learning for Industrial Anomaly Detection".


## Datasets

***

Before starting training and testing, please download the required datasets and place them in the appropriate directory.

* **MVTec AD :**
    * **Official Website:** [https://www.mvtec.com/company/research/datasets/mvtec-ad](https://www.mvtec.com/company/research/datasets/mvtec-ad)

* **VisA :**
    * **Official Repository:** [https://github.com/amazon-science/spot-diff](https://github.com/amazon-science/spot-diff)

* **MPDD :**
    * **Official Repository :** [https://github.com/stepanje/MPDD](https://github.com/stepanje/MPDD)

* **CADSD :**
    * **Related Project :** [https://github.com/IshidaKengo/SA-PatchCore](https://github.com/IshidaKengo/SA-PatchCore)
